# superstore-sales-dashboard

📊 Superstore Sales Dashboard
This is an interactive sales dashboard built using Power BI and a cleaned version of the Superstore dataset. It visualizes sales performance across region, month, and product using charts and slicers.

📁 Files Included
File	Description
Superstore_Sales_Cleaned.csv	Cleaned dataset with Order Date, Region, Sales, Profit
Dashboard.pdf	Snapshot of final Power BI dashboard
Superstore_Dashboard_Insights.pptx	PowerPoint slide with 4 key insights

📌 Key Features
Sales trends by Month-Year

Sales breakdown by Region

Scatter chart to show Sales vs Profit

Interactive Region slicer


⚙️ Data Cleaning Process
Raw data was cleaned using Python (Pandas) in Google Colab.

Key cleaning steps included:

Converting Order Date to datetime format

Creating a Month-Year column

Dropping null or irrelevant columns

Ensuring consistent formatting for Region, Sales, and Profit

The cleaned data was exported as Superstore_Sales_Cleaned.csv for use in Power BI.
